# 단발 용돈룰렛 관리 시스템 (Weflab 실시간 연동)

SOOP(아프리카TV) 방송 및 위플랩(weflab.com/alertlist)과 실시간 연동되는 맞춤형 용돈 룰렛 대시보드입니다.

---

## 🚀 빠른 시작 (실행 방법)

1. 폴더 내 **
un.bat** 파일을 더블 클릭합니다.
2. 로컬 웹 서버가 실행되며, 웹 브라우저가 자동으로 열립니다 (http://localhost:8000).
3. 브라우저에서 대시보드를 바로 사용할 수 있습니다!

---

## 📡 위플랩 (weflab.com/alertlist) 실시간 연동 방법

SOOP 로그인을 사용하는 위플랩과 **0.1초 실시간 연동**을 지원합니다.

1. 크롬(Chrome) 또는 엣지(Edge) 브라우저에 **Tampermonkey(탬퍼몽키)** 확장 프로그램이 설치되어 있는지 확인합니다.
2. 대시보드 우측 상단 **[위플랩 연동설정]** 버튼을 클릭하거나, http://localhost:8000/weflab_sync.user.js에 접속하여 스크립트를 설치합니다.
3. 브라우저에서 **https://weflab.com/alertlist** 페이지를 열어두기만 하면 끝!
   - 화면 우측 하단에 **[🟢 단발 용돈룰렛 연동]** 배지가 표시됩니다.
   - 방송 중 룰렛 및 후원이 발생할 때마다 자동으로 이 사이트에 실시간 기록됩니다.

---

## ✨ 핵심 기능

1. **방송 시작 타이머 & 서울 시간 동시 기록**:
   - 상단 **[시작]** 버튼을 누르면 방송 타이머가 흐르며, 후원 발생 시 **'방송 시작 후 경과 시간'**과 **'현재 서울 시간'**이 함께 기록됩니다.
2. **룰렛 결과 스마트 자동 파싱 (example.2 기준)**:
   - (0.6%) 1812 형태의 룰렛 결과를 자동 감지
   - 부호가 없으면 **+ 1812 (파란색 플러스)**, - 부호가 있으면 **- 500 (빨간색 마이너스)**로 자동 분류 및 전광판에 점수 반영
   - 언제든 개수 배지를 클릭하여 + / - 토글 가능
3. **스트리머(인물) 자유 관리**:
   - 상단 **[스트리머 관리]** 버튼을 통해 원하는 인물을 자유롭게 **추가, 키워드 등록, 색상 지정, 삭제** 가능
   - 채팅 메시지에 인물 이름이나 키워드가 포함되어 있으면 해당 스트리머가 자동으로 선택됩니다.
4. **시뮬레이션 & 수동 입력 (example.1 기준)**:
   - 방송 전 테스트를 위한 상단 시뮬레이션 바 제공
   - 리스트 상단 수동 추가 행을 통해 언제든 직접 후원 등록 가능
5. **실시간 통계 전광판 & 엑셀 다운로드**:
   - 각 스트리머별 누적 룰렛 점수, 총 별풍선, 후원 건수 실시간 집계
   - 0점 스트리머 표시 토글 & 전체 총합 표시 토글
   - **[엑셀]** 버튼 클릭 시 상세 후원 리스트와 스트리머별 통계가 포함된 .xlsx 파일 즉시 다운로드
